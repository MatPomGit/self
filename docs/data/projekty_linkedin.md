<u>„ARIANA"</u> - Affective Recognition, Interpretation and Neural Analysis 

# <u>lis 2024 – obecnie</u> 

The ARIANA project aims to create an innovative AI system for affect analysis, combining affective computing and psychology. By integrating data from multiple sensors (VIS, IR, ToF, eyetracker), the system will enable unconscious emotion measurement and detection of attempts to conceal them. Combining measurements with psychological tests will ensure objective response verification. This system, along with an autoaffectometer, an analytical module, and an AI communication agent, will create an objective psychometric tool for diagnostics, adaptive systems, and marketing. The device will be developed in two variants – mobile and stationary.… więcej
