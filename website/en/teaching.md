# Teaching

## Student materials

Instructions, presentations, exercises and supplementary resources are available in the [student materials catalogue](/self/materials/), on the university website and in the repositories assigned to each course. The linked course materials retain their original language.

## Consultations

For questions about courses, projects or assessment, send an email with a brief description of the problem to [m.pomianek@prz.edu.pl](mailto:m.pomianek@prz.edu.pl).

## Thesis supervision and student projects

Preferred thesis topics combine programming, artificial intelligence, image analysis, HCI, HRI, neuroinformatics and robotics. Student projects should include working software, readable code, documentation and reproducible results.

## Courses

- **Tools for Programmers:** terminal, Git, development environments and project practices
- **Algorithms and Data Structures:** computational complexity, data structures and solution analysis
- **Mobile Application Programming:** application design, architecture, frontend and backend
- **Image Analysis and Processing:** filtering, segmentation, morphology and object detection
- **Cognitive and Affective Psychoinformatics:** computational analysis of behaviour, emotions and cognitive processes
- **Affective Robotics:** human–robot interaction, perception and cognitive robotic systems
